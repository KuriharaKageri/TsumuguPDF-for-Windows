# つむぐPDF（Windows版）

見る・並べる・ひとつに紡ぐ。Mac の「プレビュー」に近い感覚で使える、軽快なPDFビューアーです。

自分でスキャンした本や書類のPDFを、気持ちよく読んで整えるために作りました。

## 入手

**[Microsoft Store のつむぐPDF のページ](https://apps.microsoft.com/detail/9PCSL1Q5BGP?hl=ja-jp&gl=JP)** から、「入手」で入れられます（無料）。新しい版は、ストアが自動で届けます。

## おもな機能

- 大きなPDFでもすばやく開く・保存する
- サムネイルのドラッグで、ページの並べ替え・削除・回転
- ほかのPDFへのページのコピー・移動、PDFの結合と分割
- 画像（JPEG・PNG・HEIC など）を並べて、1つのPDFに
- 見開き表示（表紙あり・なし、右開き・左開き）
- テキストの選択とコピー・検索（OCRで文字の入ったPDF）
- 印刷・ダークモード

使い方は、アプリの中の「使い方」（F1）にまとめてあります。

## 動かすもの

- Windows 11／Windows 10（64ビット）

## プライバシー

このアプリは、インターネットに接続しません。PDFや画像、その中身を外部へ送ることは一切ありません。広告も、アカウントの登録もありません。詳しくは [プライバシーポリシー](PRIVACY.md) をご覧ください。
